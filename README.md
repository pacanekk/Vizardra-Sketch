# Vizardra Sketch

> A modern, open-source vector graphics editor.

**Vizardra Sketch** is a fast and modern vector graphics editor built with Rust and [Iced](https://github.com/iced-rs/iced).
It aims to provide a clean, intuitive alternative to traditional vector design software.

Part of the **Vizardra** creative suite.

### Features

- Vector shapes (rectangles, paths)
- Text and typography
- Colors, fills and opacity controls
- Layer management with visibility toggles
- Undo / redo history
- Pan and zoom canvas
- Project save / load (`.vzd` format)
- PNG export
- Dark, minimal interface
- Cross-platform

### Tech Stack

- **Language:** Rust (edition 2024)
- **GUI:** Iced 0.14 + iced_aw
- **Serialization:** serde + serde_json
- **File dialogs:** rfd

### Status

🚧 **Vizardra Sketch is currently in active development.**

Features and APIs may change as the project evolves.

### Getting Started

```bash
git clone https://github.com/pacanekk/Vizardra-Sketch.git
cd Vizardra-Sketch
cargo run
```
